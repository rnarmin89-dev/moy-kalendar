Мой ритм дня — установка на Android

1. Опубликуйте содержимое папки на HTTPS-хостинге (например GitHub Pages/Netlify).
2. Откройте полученный адрес в Chrome на Android.
3. Нажмите ⋮ → Установить приложение (или Добавить на главный экран).
4. После первой загрузки календарь доступен без интернета.

Это PWA, а не APK. Просто открытие файла index.html из архива не позволит установить PWA.
